## R-1. Level check: the resolved session, not the stored plan (replaces 2.1 G1 for v3)
- **v3 writes every plan at the top rung on purpose** (program-design §8). The stored plan may contain exercises above an athlete's level.
- **New rule:** what an athlete **sees, logs, and appears with on the board** never exceeds their level, whenever level adjust is on. That's the resolved session from `resolveSession`.
- **Approach-generated personal and solo programs:** level adjust is **always on** (there's no coach to turn it off).
- **Check (replaces "stored plan never exceeds level"):** for every v3-generated session, resolve it for a beginner, an intermediate, and an advanced athlete; no resolved exercise is above that athlete's level. Run it on all templates in program-design §7.

## R-2. Sets and reps after a switch (clarifies G8 for v3)
**Sets × reps stay the same after a switch.** Three cases need a precise rule:
1. **Method downgrade** (the athlete isn't eligible for the slot's method, program-design §6):
   - **Contrast pair → two straight-set exercises.** Same exercises (each switched to the athlete's rung), same sets × reps; do all the lift's sets with normal rest, then the jump's sets. No pairing.
   - **Cluster triples → straight sets of 3.** Same sets, same reps (3).
   - **Wave (e.g., 5-3-2) → straight sets.** Same number of sets; reps = the middle wave value (3); load from the block's straight-set prescription (§5b). **This is the only allowed exception to "same reps."**
2. **Plyometric slots:** same sets × reps after the switch (e.g., Depth Jump 3 × 3 → Box Jump 3 × 3). Position emphasis (§8b, e.g., setters −20% contacts) is applied **to the plan before resolution**, so it isn't a switch effect.
3. **Contact cap after a switch:** if a switch to a one-sided rung ("each") pushes the session over the plyo contact cap (§9), drop **one set from the lowest-priority plyo slot** until it fits. This is an allowed exception; show it in the session's note ("1 jump set dropped to stay under today's jump limit").
- **Check:** after any switch, sets × reps match the plan except cases 1-wave and 3, which show the note.

## R-3. Home weeks in v3 (keeps the home-workout rules)
Recommended school + home weeks generated by v3 follow `programs/home-workouts.md` exactly:
- **H1–H8 apply** (caps, the one light home day beyond the cap, ≥ 1 day with no training, match-day rules, no back-to-back lower-heavy days, home exercise exclusions, jumps off by default).
- **Home sessions use the home archetypes** (Home Lower / Upper / Total / Light, home-workouts §4), with each slot's **default exercise = the ladder's Home / bodyweight rung** (program-design §8a). Each athlete's app then resolves it to their home equipment and level.
- **Home prescriptions use `HOME_RX`** (home-workouts §5), with the block's RPE target capped at **RPE 7** at home.
- **Check:** the 2.2 school + home checks (light home day for beginners and in-season, bodyweight defaults, H2) pass with v3 on.

## R-4. Pieces not built in 2.4.0
| Piece | Ruling | Needed to turn v3 on? |
|---|---|---|
| **Practice-load adjustment of plyo contacts** | Using the athlete's combined calendar: on a **practice day**, plyo contacts in the lift session are **−30%** (drop sets, lowest-priority plyo slot first). On the **day after a match or tournament**, **−50%**. Never below 1 set of the main plyo. | **Yes** (it's the main safeguard for jump volume) |
| **Wave loading** | Build per program-design §6 (advanced, coach-confirmed). Until built, the generator uses top set + back-offs in its place. | No |
| **Bye-week Day 3** (in-season) | When the combined calendar has no match or tournament Mon–Sun, add Day 3 = off-season Day 3 at Maintain volume (§7f). | No |

## R-5. Switching existing programs to v3
- **Don't regenerate anyone's current program mid-block.** Existing Approach-generated programs keep running until their **current 4-week block ends**; the next block is generated by v3.
- At that point the athlete (or coach, for team programs) sees: *"Your next block uses Approach's new programming."* No action is needed.
- **New programs** created after the release use v3 immediately.
- **Coach-built programs are never touched** (coach freedom).
