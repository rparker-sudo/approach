# PART A · Generator v3 on by default (`content/generator-v3-rulings.md`, follow exactly)

## A1. Default on, with an off switch (D-059)
- `generatorV3: true` in `src/lib/flags.ts`. Setting it to `false` restores the 2.3.0 generator with no other change.
- Applies to every Approach-generated program: volleyball team programs, home-week "Recommend," personal and solo programs. **Not** to coach-built programs or trainer goal defaults (`adult-goals.md` is unchanged).

## A2. R-1 · Level check on the resolved session (replaces G1 for v3)
- The stored v3 plan may contain exercises above an athlete's level. What the athlete **sees, logs, and appears with on the board** comes from `resolveSession` (G-1) and never exceeds their level whenever level adjust is on (lower level across teams, D-031).
- **Personal and solo programs:** level adjust is **always on** (no coach to turn it off).
- Every athlete-facing path shows resolved exercises only: Today, workout, history, home, board, live ticker, stations, rack rotation, exports.

## A3. R-2 · Sets and reps after a switch (clarifies G8 for v3)
Sets × reps stay the same after a switch. Precise cases:
1. **Method downgrade** (athlete not eligible for the slot's method, program-design §6):
   - **Contrast pair → two straight-set exercises.** Same exercises (each switched to the athlete's rung), same sets × reps; all the lift's sets with normal rest, then the jump's sets. No pairing.
   - **Cluster triples → straight sets of 3.** Same sets, same reps (3).
   - **Wave (e.g., 5-3-2) → straight sets.** Same number of sets; reps = the middle wave value (3); load from the block's straight-set prescription (§5b). The only allowed exception to "same reps."
2. **Plyometric slots:** same sets × reps after the switch (e.g., Depth Jump 3 × 3 → Box Jump 3 × 3). Position emphasis (§8b, e.g., setters −20% contacts) is applied **to the plan before resolution**, so it isn't a switch effect.
3. **Contact cap after a switch:** if a switch to a one-sided rung ("each") pushes the session over the plyo contact cap (§9), drop **one set from the lowest-priority plyo slot** until it fits, and show the session note: **"1 jump set dropped to stay under today's jump limit"** (or "2 jump sets…").

## A4. R-3 · Home weeks in v3
> **v1.1:** the H1–H8 rules below still apply. The home **session content** (archetypes, default exercises, `HOME_RX`) is replaced by Training's v3 home and mobility templates in **Part D** (`generator-v3-rulings.md` v1.1). If those templates aren't saved at hand-off, build R-3 as written and stop before deploy (Part D can't pass without them).
Recommended school + home weeks generated by v3 follow `programs/home-workouts.md` exactly:
- **H1–H8 apply** (caps, the one light home day beyond the cap, ≥ 1 day with no training, match-day rules, no back-to-back lower-heavy days, home exercise exclusions, jumps off by default).
- **Home sessions use the home archetypes** (Home Lower / Upper / Total / Light, home-workouts §4). Each slot's **default exercise = the ladder's Home / bodyweight rung** (program-design §8a); each athlete's app resolves it to their home equipment and level.
- **Home prescriptions use `HOME_RX`** (home-workouts §5), with the block's RPE target capped at **RPE 7** at home.
- v3 builds the weight-room days; the home-workouts rules build the home days.

## A5. R-4 · Practice-load adjustment of plyo contacts (needed to turn v3 on)
- From the athlete's **combined calendar** (TM-2; practices from the team's usual week and calendar, matches and tournaments from calendar events):
  - on a **practice day**, plyo contacts in that day's lift session are **−30%**;
  - on the **day after a match or tournament**, **−50%**.
- Drop **sets**, lowest-priority plyo slot first. **Never below 1 set of the main plyo.**
- Applied by the generator for `'approach'` sessions after position emphasis and before resolution. The R-2 case 3 cap check still runs after resolution.
- Uses only existing data. A coach never sees another team's events (neutral reason only, compliance § Multiple teams 4).

## A6. R-5 · Switching existing programs to v3
- **Don't regenerate anyone's current program mid-block.** Existing Approach-generated programs keep running until their **current 4-week block ends**; the next block is generated by v3.
- At that point the athlete (or the coach, for team programs) sees once: **"Your next block uses Approach's new programming."** No action needed. Whether it was seen is kept **on the device** (G-3; no new server field). Which generator made a block is derived from the existing program JSON (v3 blocks carry `block`; 2.3.0 programs don't).
- **New programs** created after the release use v3 immediately.
- **Coach-built programs are never touched** (coach freedom).

# PART D · Week setup before the build (D-062)
**Founder request (11/19):** "The coach has to be able to put in which days are weight room days prior to the build of the program so that is taken into account… for example I have two weight room days (Tuesday and Thursday) but I want my athletes to have an at-home workout day and an at-home mobility day… The programming needs to fit the style that I have added and discussed with Training."
**Rule:** the **coach decides the days**; **Approach's programming decides the workouts.** Generator v3 (program-design v3: blocks, warm-up → A–E, ladders, position emphasis, §9 limits) designs every day of the week, weight room, home, and mobility, as one plan.

**Problem today (2.4.0, live):**
- The builder only takes weight-room days plus a total day count; the app decides which other days are home, and there's no way to ask for a mobility day before the build.
- With v3 on, `generateV3` builds a gym week and then **relabels** non-weight-room gym sessions as home (`location: 'home'`). The home day isn't designed for home, and the week isn't designed around it.
- With v3 off (live today), builds use the 2.3.0 generator, which is why they don't look like the v3 style yet.

## D1. The Week setup card (team programs, volleyball)
Replaces the "Weight room only / Weight room + home" chips, the Weight room days row, and the Training days stepper in the builder (F19a).
- **One row per weekday,** Mon–Sun. Each row shows the day's volleyball context from the team's usual week and calendar ("Practice," "Match," "Tournament," or nothing), read-only, and a segmented choice:
  **Off · Weight room · Home workout · Mobility**
  - *Weight room:* a full session in the school weight room (the gym equipment set above).
  - *Home workout:* a full home session (each athlete's own home equipment, bodyweight by default).
  - *Mobility:* a short home mobility and care session (no load, no jumps).
- **Defaults** for a new program: the current lift-day pick as Weight room, every other day Off. When editing, the card shows what the program was built with (from `weightRoomDays`, `liftSchedule`, and each session's `location` / `mobility` flags).
- **Recommend for me:** keeps the coach's Weight room days and fills Off days with Home workout and Mobility days per `home-workouts.md` §3 (recommended totals by phase), placed by D3. The coach can change any of it before building.
- **Jumps at home** toggle stays (H7, now on this card).
- **Summary line** above Build, plain text: "2 weight room + 1 home workout + 1 mobility day." Plus, when caps apply, the per-level line (existing F19a pattern): "Beginners: 2 weight room + 1 mobility day + 1 light day (max 3 full lift days for their level)." No warnings, no blocks (D-045): the coach can choose any days; the summary says what Approach's program will give each level.
- **Not on this card:** session content. Coaches change content after the build as today (which makes that session the coach's, D-045).
- **Solo/personal programs and trainer mode:** unchanged in 2.4.1 (personal builder keeps its lift-day picker; trainer goal programs are hand-set).

## D2. What the generator does with it
1. **Days are the coach's.** Every session lands on the weekday and as the kind the coach chose. The generator never moves a coach's day, except R7 match-day moves per athlete (D-055) and per-athlete caps (item 5).
2. **Weight room days** get the v3 template for that number of weight-room days (program-design §7: 1–5 days by phase), **adjusted for the home and mobility days in the week** per Training's week table (D4). Heavy bilateral lifts, Olympic derivatives, and the main power work stay in the weight room.
3. **Home workout days** get a **v3 home session** (Training, D4): the same block, week, and A–E architecture at home rungs, designed to **complement** that week's weight-room days (cover what they don't, per Training's table), with `HOME_RX`-style prescriptions capped at RPE 7 (R-3). Jumps only if Jumps at home is on and the phase allows (H7). Home warm-up per `warmups.md` §5.
4. **Mobility days** get a **v3 mobility session** (Training, D4): mobility, care (the E-block emphasis for the athlete's position, §8b), and core; no load, no jumps; RPE ≤ 5; target length from Training (default 20 min). No warm-up card (like light home and extra recovery). It's a prescribed session (counts on the effort board like the light home day, TM-4) but **doesn't count toward the lift-day cap** and **isn't** a rest day (H3).
5. **Per-athlete limits** (generated programs, unchanged): R6 caps by level and phase count Weight room + Home workout days. An athlete over their cap gets the lowest-priority Home workout replaced by a **light home day** (H2, one per week), then dropped. H3 (≥ 1 day with no training), H4 (no home session on a match or tournament day; the day before a match, upper body or mobility only), and H5 (no back-to-back lower-heavy days across weight room and home) are met by **choosing content**, not by moving days; if a coach's days make a rule impossible (e.g., no day off), that athlete's lowest-priority non-weight-room session becomes Off and the summary line says so.
6. **Season context:** practices, matches, and tournaments from the combined calendar shape content (R7 placement, practice-load plyo contacts R-4, in-season Day 1 heavy / Day 2 fast). In-season with two weight-room days uses the Maintain template on those days.
7. **Session length:** each day uses its target (§4a; per weekday if set; phase default otherwise: home 30, mobility 20) and runs through `fitSession`.
8. **Replace** the `generateV3` relabeling: no gym session is ever turned into a home session by changing its `location`.

## D3. Recommend placement (when the coach taps Recommend)
Fills Off days only. Home workout days go on non-match days not next to a lower-heavy weight-room day where possible; Mobility goes the day after a match or tournament, or the day after the hardest weight-room day; keeps ≥ 1 day Off. Training confirms in D4.

## D4. Training content needed (blocks Part D)
In `content/generator-v3-rulings.md` **v1.1** (or a new `content/programs/home-and-mobility-v3.md`):
1. **Week table:** for 1–4 weight-room days × 0–3 home workout days × 0–2 mobility days, by phase: which v3 template each weight-room day uses, what each home day covers, and how weight-room templates change when home days exist (what moves to home, what stays).
2. **v3 home session** templates: block letters at home rungs, by block and week, with prescriptions (replacing the old archetypes and `HOME_RX` for v3 programs), and the H7 jump rule.
3. **v3 mobility session:** content by phase and position, length, effort, and how it differs from the H2 light home day and the extra recovery sessions.
4. **Rulings:** mobility on a match day (allowed or not), placement rules for Recommend (D3), and which per-athlete cap replacement comes first (item D2.5).
5. **Acceptance examples** for the founder's week (below) and two more (in-season with a Saturday tournament; beginner over cap).

## D5. Data
**No new fields.** The setup is the generator input; the result is stored in what exists: `weightRoomDays`, `liftSchedule`, each session's `location` ('school' | 'home') and `mobility` / `light` flags, `homeJumps`. The card restores itself from those. If the build needs any new key, **stop and ask** (G-5).

- [ ] **The founder's week:** Weight room Tue and Thu, Home workout Sat, Mobility Mon (off-season, intermediate, full weight room). Build produces exactly 4 sessions on those days: Tue and Thu are v3 weight-room sessions (warm-up → A–E) per Training's week table; Sat is a v3 home session that covers what Tue/Thu don't, per the table; Mon is a v3 mobility session.
