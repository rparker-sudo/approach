# 2.3.1 acceptance report: custom exercises

**Source:** owner request (Ryan, November 16, 2026): "All programs should have the option to create a custom exercise from the coach themselves." This isn't in a planning spec.

**Ryan's choices:**
- saved inside each program;
- the coach sets type and level;
- fields: name, one-line cue, equipment, how-to steps, weighted or bodyweight;
- volleyball and trainer teams;
- version 2.3.1.

**Branch:** `v2.3.1` (app only; the website doesn't change). **Status:** not deployed. **No migration.**

## Flags
**Planning team:**
- The trainer spec reserves 2.3.1 for the AI assistant, which now needs another number.
- CLAUDE.md says "volleyball teams don't change". This is an owner-approved change for volleyball coaches.

**Legal:**
- Confirm that coach-written exercises inside the program JSON need no T4 row (no data about users).
- Confirm that coach-written text, like coach notes, isn't subject to our claim-word rule.

**Training:**
- A coach could label a heavy lift as "Accessory". A CSCS review could add a confirmation step.
- Cardio and Olympic lifts can't be created as custom exercises.
- Home sessions use library exercises of the same movement.
