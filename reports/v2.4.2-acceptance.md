## Judgment calls (for review)
1. **A-3 phase switch:** the plan switches the **block and phase by date** (prescriptions, plyo caps, Maintain cycles). The stored weight-room sessions stay the templates of the phase the program was built in; a program that runs into preseason doesn't swap in the PRE3 sessions. Swapping templates by date would need extra session sets in the program and routing in the week plan; say if you want it.
2. **Week notes by week:** the stored note is week 1's; each athlete's session shows that week's note (the same way the block prescription already works).
3. **Rotation rounds** are stored at build; the deload and taper lower each position's sets but not the room clock's rounds.
4. **D-031 for auto-created rack groups:** the coach app doesn't get another team's level, only whether an athlete's exercises resolve differently; such an athlete counts one level lower when racks are made. Nothing is shown.
5. **Fillers** when a rotation is short or the room lacks an item come from the day's core/E items, then a fixed pool (Dead Bug, Wall Slide, Y-T-W, Bent-Knee Calf Raise, Tibialis Raise, Side Plank).
6. **Stations style** makes one station per rack (2–6).
